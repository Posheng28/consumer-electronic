# 消費性電子產業分析報告 2026 · 互動版

> 下一個 Super Cycle 是否輪到 AI 終端？

交易室用產業研究報告的互動網頁版。單一自含 HTML（手刻 SVG 圖表、深色主題），涵蓋總體格局、記憶體缺料、終端分層（AI PC / 手機 / 眼鏡 / 機器人 / 邊緣 AI）、歷史循環對照、情境模型、供應鏈與個股觀察清單。

## 內容亮點

- **互動圖表**：AI PC 滲透率、記憶體漲幅、BOM 成本、AI 眼鏡與機器人出貨、半導體大循環等（純前端 SVG，無外部相依）。
- **歷史循環驗證**：以 TWSE 官方歷史股價，標出大立光、南亞科、國巨、微星四輪「谷底 → 啟動 → 高點 → 反轉」的關鍵節點，並附當時事件與營收/EPS 佐證。
- **本輪個股對照**：世芯、大立光、奇鋐、錼創、鴻海、瑞昱的真實股價對照產業 catalyst。
- **個股觀察清單**：AI/ASIC、AI PC、iPhone 鏈、AI 眼鏡、IPC/邊緣 AI、機器人、智慧家庭，並標註各分類的日本世界龍頭。
